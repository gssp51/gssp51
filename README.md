### [PayFlow Pro: Payroll & Workforce Timekeeping](https://github.com/gssp51/PayFlowPro-Portfolio)

An ASP.NET Core MVC web app for the office and a React Native iPad kiosk for field workers, both using one C# Web API and one SQL Server database through Entity Framework Core.

- Office and Field timekeeping workflows (personal clock for office staff; shared iPad with Employee ID, shift selection, signature and meal-break questions for field crews)
- Role- and region-based security with JWT authentication and ASP.NET Core Identity
- Timesheet approvals, locking and audited reopening, plus payroll processing
- Demo overtime calculation (hours above 40 at 1.5x), implemented only in the backend; this is a demonstration rule, not payroll or tax compliance
- 366 .NET (xUnit) tests and 48 React Native (Jest) tests passing
